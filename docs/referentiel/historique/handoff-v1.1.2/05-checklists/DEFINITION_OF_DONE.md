# Definition of Done globale

## Audit
- [ ] État du dépôt vérifié, pas supposé.
- [ ] Commandes existantes exécutées.
- [ ] Matrice keep/adapt/migrate/retire complète.
- [ ] Risques et rollback documentés.

## Contrats
- [ ] 8/8 schémas présents.
- [ ] Statuts limités à draft/review/validated/deprecated.
- [ ] `version` positive.
- [ ] Contrats fermés.
- [ ] Provenance structurée.
- [ ] Evidence fixée sans polymorphisme ambigu.

## Fixtures et validation
- [ ] Positives, négatives et WARNING.
- [ ] Niveaux 1 à 4 exécutables.
- [ ] Rule IDs stables.
- [ ] Rapports déterministes.
- [ ] Zéro correction silencieuse.
- [ ] Tests graphes, historique et multi-objets.

## CI et migration
- [ ] Fixture invalide bloque la CI.
- [ ] Corpus valide passe.
- [ ] WARNING conservés.
- [ ] Migration pilote sans régression critique.
- [ ] Rollback documenté.
