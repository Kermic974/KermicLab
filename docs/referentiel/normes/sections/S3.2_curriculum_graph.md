# S3.2 — Curriculum Graph et CurriculumMapping

| Section | Version | Statut | Dépend de |
|---|---|---|---|
| S3.2 | 1.2.0 (intègre la mise à niveau v1.1.2) | 🟢 ADOPTÉE (reconstruite) | S2, S3.1 |

## 1. Rôle

**[B]** Le Curriculum Graph exprime le **contexte institutionnel** : programmes, niveaux, domaines. Il est séparé du Knowledge Graph.

```text
Curriculum ─┬─ Stage  (cycle, classe)
            └─ Domain (thème du programme)
                  ▲
          CurriculumMapping
                  ▲
      Notion / MicroSkill / Skill
```

## 2. Objets

| Objet | Rôle | Origine |
|---|---|---|
| Curriculum | un programme officiel, dans **une** édition institutionnelle | [B] ; « une édition » [P] |
| Stage | un niveau de ce programme (cycle ou classe) | [B] ; types [P] |
| Domain | un domaine ou thème de ce programme | [B] |
| CurriculumMapping | place un nœud du Knowledge Core dans un Stage (et éventuellement un Domain) d'un Curriculum, avec un rôle | [B] |

## 3. Rôles [B]

| Rôle | Sens |
|---|---|
| `introduced` | première rencontre institutionnelle |
| `reinforced` | reprise et entraînement |
| `consolidated` | stabilisation attendue |
| `deepened` | approfondissement, extension |
| `mobilized` | utilisée comme outil dans un autre apprentissage |

## 4. Règles

| # | Règle | Origine |
|---|---|---|
| S3.2-1 | Un rôle curriculaire **ne crée pas** de Relation pédagogique. Placer une Notion avant une autre dans un programme n'implique pas `requires`. | [B] |
| S3.2-2 | Clé sémantique : `projectionKey = object + curriculum + stage + domain\|null + role` | [B] v1.1.2 |
| S3.2-3 | `version` n'appartient pas à `projectionKey` | [B] v1.1.2 (audit v1.1.1, correction 2) |
| S3.2-4 | Une même projection canonique a une seule identité ; ses révisions incrémentent `version` | [B] (S4.2 v1.1.2 §6) |
| S3.2-5 | Modifier `object`, `curriculum`, `stage`, `domain` ou `role` crée une nouvelle identité | [B] (S4.2 v1.1.2 §6) ; « sans exception » [P] |
| S3.2-6 | Le Stage et le Domain d'un mapping appartiennent au Curriculum du mapping | [D] |
| S3.2-7 | Un même nœud peut avoir plusieurs mappings dans un même Stage, avec des rôles différents | [D] (le rôle fait partie de la clé) |
| S3.2-8 | Les données apprenant n'appartiennent jamais au Curriculum Graph | [B] |
