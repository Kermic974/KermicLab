# S4.5 — Contrats du Curriculum Graph : Curriculum, Stage, Domain

| Section | Version | Statut | Dépend de |
|---|---|---|---|
| S4.5 (numéro proposé) | 1.2.0 | 🟢 ADOPTÉE | S3.2, S4.1, S4.2, S4.7 |

## 1. Curriculum

**[P]** (réponse à OPEN-008) **Un Curriculum = un programme officiel dans une édition institutionnelle.** Une nouvelle édition (nouveau BO, nouvelle rentrée d'application) est un **nouvel objet**, avec un nouvel `id`. Elle n'est pas une nouvelle `version` du même objet. Raison : les CurriculumMappings désignent un Curriculum par son `id` ; un programme dont le contenu changerait sous un même `id` rendrait les placements existants ambigus.

| Champ | Obligatoire | Type | Règle | Origine |
|---|---|---|---|---|
| `id` | oui | ID | `curriculum.<juridiction>.<nom>` (S4.1) | [B] champ ; [P] pattern |
| `type` | oui | constante | `"curriculum"` | [B] |
| `jurisdiction` | oui | chaîne | code pays ISO 3166-1 alpha-2 en minuscules (`fr`) | [B] champ ; [P] format |
| `authority` | oui | chaîne | autorité émettrice, 1 à 200 caractères (« Ministère de l'Éducation nationale ») | [B] |
| `title` | oui | chaîne | titre officiel, dans la langue de la juridiction, 1 à 300 caractères | [B] |
| `curriculumVersion` | oui | chaîne | édition institutionnelle : `^[0-9]{4}(-[a-z0-9]+)*$` (année de publication ou d'application, suffixe facultatif : `2020`, `2019-bo-1`) | [B] champ ; [P] format |
| `status` | oui | énumération | S4.2 | [B] |
| `version` | oui | entier ≥ 1 | S4.2 (révision de l'enregistrement) | [B] |
| `provenance` | **oui** [P] | Provenance, `type = institutional` | S4.7 ; contrôlée par `S4-CUR-014` | [P] |
| `replacedBy` | non | ID `curriculum` | S4.2 §6 (édition suivante) | [B] |

Champs d'identité : `id`, `jurisdiction`, `curriculumVersion`. **[P]** Corriger le titre ou l'autorité est une révision (`version` + 1). Changer d'édition crée un nouveau Curriculum.

Unicité **[P]** : (`jurisdiction`, `authority`, `title`, `curriculumVersion`) est unique parmi les Curricula.

**[R]** En France, un programme officiel couvre un enseignement et un niveau (« Mathématiques, cycle 4 », « Mathématiques, enseignement de spécialité, classe de première »). Chacun est donc un Curriculum distinct. La distinction tronc commun / spécialité est portée par le Curriculum, pas par un Stage.

## 2. Stage

| Champ | Obligatoire | Type | Règle | Origine |
|---|---|---|---|---|
| `id` | oui | ID | `stage.<juridiction>.<nom-du-curriculum>.<code>` | [B] champ ; [P] pattern |
| `type` | oui | constante | `"stage"` | [B] |
| `curriculum` | oui | ID `curriculum` | — | [B] |
| `stageType` | oui | énumération | `cycle` ou `classe` | [B] champ ; [P] valeurs (OPEN-006) |
| `code` | oui | chaîne | segment d'ID (S4.1 §1), égal au 4e segment de `id` : `cycle-4`, `cinquieme`, `seconde` | [B] champ ; [P] format |
| `label` | oui | LocalizedText | S4.3 §1 | [B] |
| `order` | oui | entier ≥ 1 | rang institutionnel parmi les Stages de même `curriculum`, même `parent` et même `stageType` | [P] |
| `parent` | non | ID `stage` | un Stage `classe` peut avoir pour parent un Stage `cycle` du même Curriculum ; un Stage `cycle` n'a pas de parent | [P] (DOC-17) |
| `status`, `version` | oui | — | S4.2 | [B] |
| `replacedBy`, `provenance` | non | — | S4.2, S4.7 | [B], [P] |

Champs d'identité : `id`, `curriculum`, `stageType`, `code`.

**[D]** La hiérarchie des Stages a au plus deux niveaux (cycle → classe) : elle est acyclique par construction.

**[P]** Cible « cycle 1 → terminale » : les cycles 1 à 4 sont des Stages `cycle`, les classes (`petite-section` à `terminale`) des Stages `classe`. Au lycée, une classe n'a pas de parent.

## 3. Domain

| Champ | Obligatoire | Type | Règle | Origine |
|---|---|---|---|---|
| `id` | oui | ID | `domain.<juridiction>.<nom-du-curriculum>.<nom>` | [B] champ ; [P] pattern |
| `type` | oui | constante | `"domain"` | [B] |
| `curriculum` | oui | ID `curriculum` | — | [B] |
| `label` | oui | LocalizedText | — | [B] |
| `parent` | non | ID `domain` | même Curriculum ; sous-domaine | [P] (DOC-17) |
| `order` | non | entier ≥ 1 | rang parmi les Domains de même parent | [P] |
| `status`, `version` | oui | — | S4.2 | [B] |
| `replacedBy`, `provenance` | non | — | S4.2, S4.7 | [B], [P] |

Champs d'identité : `id`, `curriculum`.

## 4. Exemples (normatifs)

```json
{
  "id": "curriculum.fr.mathematiques-cycle-4-2020",
  "type": "curriculum",
  "jurisdiction": "fr",
  "authority": "Ministère de l'Éducation nationale",
  "title": "Programme de mathématiques du cycle 4",
  "curriculumVersion": "2020",
  "status": "draft",
  "version": 1,
  "provenance": { "type": "institutional", "reference": "BO n° 31 du 30 juillet 2020" }
}
```

```json
{
  "id": "stage.fr.mathematiques-cycle-4-2020.quatrieme",
  "type": "stage",
  "curriculum": "curriculum.fr.mathematiques-cycle-4-2020",
  "stageType": "classe",
  "code": "quatrieme",
  "label": { "fr": "Quatrième" },
  "order": 2,
  "parent": "stage.fr.mathematiques-cycle-4-2020.cycle-4",
  "status": "draft",
  "version": 1
}
```

## 5. Règles

| Rule ID | Niveau | Sévérité | Origine | Règle |
|---|---|---|---|---|
| S4-CUR-001 | 2 | ERROR | B | Un Curriculum respecte son contrat. |
| S4-CUR-002 | 2 | ERROR | P | `jurisdiction` respecte `^[a-z]{2}$`. |
| S4-CUR-003 | 2 | ERROR | P | `curriculumVersion` respecte `^[0-9]{4}(-[a-z0-9]+)*$`. |
| S4-CUR-004 | 4 | ERROR | P | (`jurisdiction`, `authority`, `title`, `curriculumVersion`) est unique parmi les Curricula. |
| S4-CUR-005 | 2 | ERROR | B | Un Stage respecte son contrat ; `stageType` ∈ {`cycle`, `classe`}. |
| S4-CUR-006 | 2 | ERROR | P | `code` est égal au 4e segment de l'`id` du Stage. |
| S4-CUR-007 | 3 | ERROR | P | Le `parent` d'un Stage appartient au même Curriculum. |
| S4-CUR-008 | 3 | ERROR | P | Le `parent` d'un Stage `classe` est un Stage `cycle` ; un Stage `cycle` n'a pas de `parent`. |
| S4-CUR-009 | 4 | ERROR | D | `code` est unique parmi les Stages d'un même Curriculum (garanti par construction par `S4-ID-007`, `S4-ID-009` et `S4-CUR-006` ; conservé comme invariant). |
| S4-CUR-010 | 4 | ERROR | P | `order` est unique parmi les Stages de même `curriculum`, même `parent` et même `stageType`. |
| S4-CUR-011 | 2 | ERROR | B | Un Domain respecte son contrat. |
| S4-CUR-012 | 3 | ERROR | P | Le `parent` d'un Domain appartient au même Curriculum. |
| S4-CUR-013 | 4 | ERROR | P | La hiérarchie des Domains est acyclique. |
| S4-CUR-014 | 2 | ERROR | P | Un Curriculum porte une `provenance` de `type = institutional`. |
