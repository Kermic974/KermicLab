## 2. `projectionKey` [B] v1.1.2

```text
projectionKey = object + curriculum + stage + domain|null + role
```

| # | Règle | Origine |
|---|---|---|
| 2.1 | `version` est exclue de `projectionKey`. | [B] (audit v1.1.1, correction 2) |
| 2.2 | Même projection canonique → même `id` → `version` croissante. | [B] (S4.2 v1.1.2 §6) |
| 2.3 | Modifier `object`, `curriculum`, `stage`, `domain` ou `role` crée une nouvelle identité, **sans exception**. | [B] ; « sans exception » [P] (S42-05) |
| 2.4 | `projectionKey` est unique parmi **tous** les CurriculumMappings, quel que soit leur statut. | [P] |

Champs d'identité (immuables) : `id`, `object`, `curriculum`, `stage`, `domain`, `role`.

**[D]** Conséquence de 2.2, 2.4 et du caractère terminal de `deprecated` (S4.2 §2) : une projection dépréciée ne peut pas être réaffirmée telle quelle. Si l'institution réintroduit le même placement, c'est dans une **nouvelle édition** du programme (nouveau Curriculum, S4.5 §1) : la clé diffère alors par `curriculum`.

## 3. `evidence` [P] (réponse à OPEN-004)

- Facultatif en `draft` et en `review`.
- **Au moins un élément** dès que `status` ∈ {`validated`, `deprecated`}.
- **Raison** : un placement curriculaire affirme un fait institutionnel. Il doit pouvoir être vérifié dans le texte officiel, en général un extrait de programme (`kind = programme-excerpt`).

## 4. Exemple (normatif)

```json
{
  "id": "curriculum-mapping.fr.pythagore-quatrieme-introduit",
  "type": "curriculum-mapping",
  "object": "notion.mathematiques.theoreme-de-pythagore",
  "curriculum": "curriculum.fr.mathematiques-cycle-4-2020",
  "stage": "stage.fr.mathematiques-cycle-4-2020.quatrieme",
  "domain": "domain.fr.mathematiques-cycle-4-2020.espace-et-geometrie",
  "role": "introduced",
  "status": "draft",
  "version": 1,
  "provenance": { "type": "migration", "migratedFrom": "catalogue/pythagore/fiche.md#niveaux" }
}
```

## 5. Règles

| Rule ID | Niveau | Sévérité | Origine | Règle |
|---|---|---|---|---|
| S4-MAP-001 | 2 | ERROR | B | Un CurriculumMapping respecte son contrat ; `role` parmi les 5 valeurs. |
| S4-MAP-002 | 2 | ERROR | B | `provenance` est présente. |
| S4-MAP-003 | 2 | ERROR | P | `evidence` contient au moins un élément quand `status` ∈ {`validated`, `deprecated`}. |
| S4-MAP-004 | 3 | ERROR | B | `object` désigne une Notion, une MicroSkill ou une Skill. |
| S4-MAP-005 | 3 | ERROR | D | Le `stage` appartient au `curriculum` du mapping. |
| S4-MAP-006 | 3 | ERROR | D | Le `domain`, s'il est présent, appartient au `curriculum` du mapping. |
| S4-MAP-007 | 4 | ERROR | B | `projectionKey` est unique parmi tous les CurriculumMappings. |
| S4-MAP-008 | 4 | ERROR | B | Les champs de la clé d'un mapping existant ne changent pas (cas particulier de `S4-ID-010`). |
