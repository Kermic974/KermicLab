# S3 — Synthèse

| Section | Version | Statut |
|---|---|---|
| S3 (synthèse) | 1.2.0 | synthèse, sans autorité propre |

| Espace | Exprime | Objets | Texte d'autorité |
|---|---|---|---|
| Knowledge Graph | vérités pédagogiques intrinsèques | Relation (7 types) | S3.1 |
| Curriculum Graph | contexte institutionnel | Curriculum, Stage, Domain | S3.2 |
| Interface | placement d'un nœud dans un programme | CurriculumMapping | S3.2, S4.6 |

Séparations à ne jamais franchir :

1. Le curriculum ne crée pas de Relation pédagogique (S3.1-9, S3.2-1).
2. Une Relation ne porte aucun niveau scolaire.
3. Les identifiants du Knowledge Core ne portent ni classe, ni cycle, ni niveau, ni version de programme (S4.1).
