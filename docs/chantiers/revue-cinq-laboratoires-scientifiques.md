# Revue pédagogique, scientifique et accessibilité des cinq laboratoires

Ce document est un registre de preuves à compléter par des relecteurs humains. Les cases non cochées ne doivent pas être interprétées comme conformes.

## Grille commune

Pour chacun des cinq laboratoires :

- [ ] objectif observable et niveau de prérequis explicités ;
- [ ] distinction claire entre observation, modèle, loi et simulation ;
- [ ] variables, unités, conventions et repère explicités ;
- [ ] hypothèses et domaine de validité visibles avant ou pendant la manipulation ;
- [ ] équations/règles vérifiées sur des cas nominaux et limites ;
- [ ] précision et méthode numériques documentées ;
- [ ] source institutionnelle ou scientifique renseignée ;
- [ ] tâche de prédiction avant manipulation ;
- [ ] activité guidée puis tâche de transfert ;
- [ ] feedback expliquant l’erreur sans seulement donner la réponse ;
- [ ] parcours complet au clavier ;
- [ ] alternatives textuelles équivalentes ;
- [ ] graphique doublé d’un tableau de données ;
- [ ] résultats et changements d’état annoncés de façon accessible ;
- [ ] couleurs, contrastes, focus, zoom, reflow et réduction des animations vérifiés ;
- [ ] aucune donnée personnelle ou état d’apprenant stocké dans S6.
