# Chantier : Support

**Niveau actuel : 0 (formulaire simple)**

- Lien « Signaler un problème » dans le chat → `POST /api/support` → issue GitHub label `support` (filtrée contre les données personnelles).
- Modèles d'issues : bug, demande de maquette, support.

Prochaines étapes : réponse automatique de premier niveau par agent, FAQ générée à partir des issues fermées.
