# ADR 0018 — Défi express généré via l'alias AI Gateway `custom/haiku`

- Date : 2026-11-06 — Statut : accepté
- Contexte : le défi express proposait cinq questions fixes sur le cercle trigonométrique. Le propriétaire souhaite cinq défis aléatoires, générés à la volée par la gateway IA avec l'alias de modèle `custom/haiku`, un quota de 3 générations par jour réglable dans l'écran Configuration, et la banque R2 en phase 2.
- Décision :
  1. **Endpoint `POST /api/defi`** (même contrôle d'origine et même limitation de débit que `/api/chat`). Le corps contient uniquement `langue`, `matiere` (identifiant validé) et `utiliserLlm`. Aucun texte libre du navigateur n'est accepté ni envoyé au modèle.
  2. **Tirage serveur** : 5 notions distinctes du catalogue (hors matière `jeux`, dans la matière courante de l'élève si elle existe, sinon tout le catalogue) et un format chacune parmi `qcm`, `vrai-faux`, `situation`, `intrus`, avec `crypto.getRandomValues`. La variété ne dépend jamais du modèle.
  3. **Un seul appel** à l'alias `custom/haiku` (variable `MODELE_DEFI`) via le binding `AI` et `kermiclab-gateway`, au format chat completions avec JSON Schema strict. La fonction `appelerAliasGateway` de `llm.js` applique la pseudonymisation comme les autres appels. Le message ne contient que les tirages et un extrait borné (1 500 caractères) du texte pédagogique publié de chaque notion. Cache et logs gateway désactivés. L'en-tête `cf-aig-max-attempts` n'est pas envoyé, pour laisser la gateway basculer entre les modèles de l'alias.
  4. **Exception à AGENTS.md §4** : Haiku est le modèle principal du défi seulement (le tuteur garde Workers AI en premier). L'alias permet de changer de modèle sur la gateway sans redéployer.
  5. **Validation stricte** de chaque défi : notion et format identiques au tirage, 3 choix (2 pour vrai-faux) distincts et courts, index de la bonne réponse valide, longueurs bornées, ni lien ni balise, modération `analyser()` sur tous les textes. Un défi invalide est retiré ; l'interface complète le lot avec la banque fixe (i18n). Sans défi valide, panne ou refus : banque fixe.
  6. **Quota séparé du tuteur** : table D1 `defis_llm` (ID de session aléatoire, expiration, compteur, verrou), au plus `DEFI_GENERATIONS_JOUR` générations (3 par défaut, de 0 à 10) par session de 24 h, réservation atomique avec un seul appel en vol. Une génération est comptée même si l'appel échoue (prudence). Le budget de 1 000 tokens du tuteur n'est pas consommé. Purge quotidienne avec les sessions.
  7. **Écran Configuration** : réglage « Défis inédits préparés par l'IA » (désactivé, 1 à N par jour, N donné par `/api/llm/status`), mémorisé sur l'appareil, et nombre de lots restants. Le défi n'appelle l'IA que si l'interrupteur « Utiliser l'IA » de la session est activé (consentement explicite) ; sinon il sert la banque fixe, sans appel ni cookie.
  8. **Transparence** : chaque défi généré indique son format, sa notion source avec « Revoir la notion », et un bouton « Signaler cette question » (support existant). Les XP restent locaux (`enregistrerDefi`, inchangé).
  9. **Phase 2** : banque de défis validés dans R2 (préfixe `defis/`, sans donnée utilisateur) pour réduire les coûts et permettre une relecture humaine.
- Limites : la validation ne prouve pas l'exactitude d'un fait généré ; l'ancrage sur le catalogue et le signalement réduisent le risque, une relecture pédagogique reste nécessaire. Le format exact de réponse du binding pour un alias (`choices[0].message.content` ou `response`) est géré dans les deux cas mais doit être vérifié en production. Supprimer le cookie crée une nouvelle session et donc un nouveau quota (comme ADR 0016).
- English summary: the quick challenge now asks the AI Gateway model alias `custom/haiku` (through `kermiclab-gateway`, JSON Schema, pseudonymized, no cache/logs) for 5 challenges on catalogue topics and formats drawn at random by the server. Only server-side catalogue excerpts are sent. Each challenge is strictly validated and moderated; invalid ones are replaced by the fixed question bank, which also serves when AI is off, unconsented, over quota or failing. A separate D1 quota allows `DEFI_GENERATIONS_JOUR` (default 3) generations per 24-hour session; users can lower it in Settings. An R2 bank of validated challenges is planned for phase 2.
- Références : [Model aliases](https://developers.cloudflare.com/ai-gateway/features/routing/model-aliases/), [binding Workers](https://developers.cloudflare.com/ai-gateway/usage/worker-binding-methods/), ADR 0016.
