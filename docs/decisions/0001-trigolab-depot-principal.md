# ADR 0001 — Le MVP est construit dans le dépôt `trigoLab`

- Date : 2026-10-31 — Statut : accepté (décision du propriétaire)
- Contexte : le cahier des charges nomme le dépôt principal `kermiclab` ; seul `kermic974/trigoLab` existe.
- Décision : construire le MVP dans `trigoLab`. Le nom de code reste Kermiclab ; un renommage du dépôt reste possible (GitHub redirige les anciennes URL).
