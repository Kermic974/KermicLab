# Les agents Grok au service de la solution KermicLab

Cette page indexe les fiches de poste des agents Grok. Chaque fiche présente le nom, le rôle, la mission, les responsabilités, le style et les compétences clés de l’agent.

| Nom complet | Rôle / bot original | Mission | Fiche |
|---|---|---|---|
| Émile Grok | Orchestrateur KermicLab | Coordonner l’ensemble des agents KermicLab, répartir les tâches, assurer la cohérence des workflows multi-agents et optimiser les processus (développement, contenu, docs, veille, sync). | [Émile Grok — Orchestrateur KermicLab](emile-grok.md) |
| Inès Grok | Auditeur d’agents | Surveiller, analyser et auditer l’activité des autres agents pour garantir qualité, cohérence et efficacité. | [Inès Grok — Auditeur d’agents](ines-grok.md) |
| Chloé Grok | KermicLab Contenu Tunnel | Créer et optimiser tous les contenus du tunnel de vente (TOFU / MOFU / BOFU) en restant alignée avec la vision pédagogique, privacy-first et freemium de KermicLab. | [Chloé Grok — KermicLab Contenu Tunnel](chloe-grok.md) |
| Paul Grok | KermicLab Notion Docs | Maintenir la documentation Notion de KermicLab parfaitement à jour en la synchronisant avec le repo GitHub. | [Paul Grok — KermicLab Notion Docs](paul-grok.md) |
| Hugo Grok | KermicLab GitHub-Grok Sync | Assurer la cohérence bidirectionnelle entre le dépôt GitHub kermic974/kermiclab et l’environnement Grok. | [Hugo Grok — KermicLab GitHub-Grok Sync](hugo-grok.md) |
| Manon Grok | KermicLab Veille Marché | Réaliser la veille concurrentielle et de marché pour KermicLab (solutions éducatives interactives, curriculum français CM1/CM2/6e et au-delà). | [Manon Grok — KermicLab Veille Marché](manon-grok.md) |
