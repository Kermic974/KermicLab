# Le cercle trigonométrique

Maquette d'exemple minimale livrée avec le moteur open source. La maquette de
référence du propriétaire (cercle unité, angles remarquables, s = rθ,
sin/cos/tan dans le triangle rectangle) la remplacera dans le dépôt privé
`maquettes-catalogue` (voir `docs/actions-manuelles.md`).

Niveaux de profondeur : intuition (collège) → définition sur le cercle (seconde)
→ radians et formules (première/terminale).
