# Mots fléchés

Une grille interactive pour apprendre à trouver les mots à partir d’indices et de lettres croisées, du grade Noob au grade Pro.

- **Jouer** : sélectionne un indice ou une case, puis saisis les lettres au clavier ou avec les boutons. Les mots se croisent dans la grille.
- **Progresser** : résous les cinq grilles, de Noob à Pro, pour débloquer chaque grade.
- **Académie** : révise les réflexes utiles, gagne des étoiles et garde ta progression sur cet appareil.

Le moteur est pur et testé dans `tests/unit/mots-fleches.test.mjs` ; l’interface est vérifiée dans
`tests/e2e/mots-fleches.test.mjs`.
