# Security Policy / Politique de sécurité

## Reporting a vulnerability

Please **do not open a public issue**. Report vulnerabilities privately through
[GitHub private vulnerability reporting](https://github.com/kermic974/trigoLab/security/advisories/new).
We aim to acknowledge reports within 7 days.

This service is used by minors: reports involving personal data exposure, content-safety bypasses
or prompt injection that leads to inappropriate content are treated as high severity.

## Signaler une vulnérabilité

Merci de **ne pas ouvrir d'issue publique**. Utilisez le
[signalement privé de vulnérabilité GitHub](https://github.com/kermic974/trigoLab/security/advisories/new).
Nous accusons réception sous 7 jours. Les contournements de la modération ou toute exposition de données
personnelles sont traités en priorité haute (public mineur).

## Supported versions

Only the latest `main` branch is supported.
